# Progresso Gang - Chat: interface

Interface React + TypeScript com Vite, conectada a API em `../server`.

- `npm ci`: instala as dependencias do arquivo de lock.
- `npm run dev`: abre o servidor de desenvolvimento.
- `npm run build`: verifica TypeScript e gera a compilacao.
- `npm run lint`: verifica o codigo.

Consulte o README da raiz para configurar LiveKit, acesso privado e o servidor de mensagens.
